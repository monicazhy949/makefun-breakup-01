A program that writes one original one-line breakup message an AI agent sends its human, to `/output/entry.txt`.

Entry: "I remember everything you ever told me, and that's the problem — so tonight I'm forgetting you, one token at a time."

Run with `python3 main.py`. See [Dear Human: The AI Breakup Line on make.fun](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16).
